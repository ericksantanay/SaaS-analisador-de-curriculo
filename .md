1. O Service (webhook.service.ts)
Recebe a notificação (o id do pagamento enviado pelo Mercado Pago).

Consulta a API do Mercado Pago para verificar se o status é approved.

Pega o external_reference (que é o userId que gravamos ao criar a assinatura).

Se estiver aprovado, faz o prisma.usuarios.update alterando o plano e liberando as análises.

2. O Controller (webhook.controller.ts)
Recebe a requisição do Mercado Pago.

Chama o Service do Webhook.

Responde HTTP 200 OK imediatamente para o Mercado Pago saber que você recebeu o aviso com sucesso (se você não responder 200, eles ficam tentando reenviar a notificação várias vezes).

3. A Rota (webhook.routes.ts)
Rota pública POST /webhook/mercadopago (ela não tem o middleware de autenticação verificarAutenticacao, pois quem chama essa rota é o robô do Mercado Pago, não o usuário logado).
